# 🎓 T8: materiais de curso

Materiais, conteúdos e exercícios usados nas aulas da turma **T8** da PdA.

## 📁 Estrutura

| Pasta | O que tem |
|---|---|
| [`m1/`](m1/) | Módulo 1: JavaScript (arrays de objetos, módulos ES e validação com Zod) e o projeto final do módulo |
| [`m2/`](m2/) | Módulo 2: banco de dados (modelagem relacional, SQL e bancos não relacionais) |
| [`projetos/`](projetos/) | Projetos que **atravessam várias aulas** e evoluem aos poucos |

## 🧭 Como cada aula é organizada

- `README.md`: o material do aluno (conteúdo, exercício em dupla e exercícios para casa).
- `gabarito.md`: as respostas comentadas. Só é publicado **no fim da aula**.
- `revisao/`: a aula de revisão (`revisao.md`) e o gabarito dela (`gabarito.md`), quando houver.
- `exercicios/async/`: a lista de exercícios para casa, quando ela não está no `README.md`.
- `livecoding/`: o código feito ao vivo em aula.

## 🛠️ Projetos

| Projeto | O que é |
|---|---|
| [`lojagil-validacao`](projetos/lojagil-validacao/) | Biblioteca de validação de pedidos da LojaÁgil (módulos ES e Zod) |

Para rodar um projeto, entre na pasta dele e instale as dependências:

```bash
cd turmas/t8/projetos/lojagil-validacao
npm install
```
