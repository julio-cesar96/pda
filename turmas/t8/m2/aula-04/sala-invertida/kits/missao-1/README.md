# 🧰 Kit da Missão 1: express.Router e controllers

Este kit é o ponto de partida da **Missão 1** da sala de aula invertida. A missão completa (a tarefa, o roteiro da mini-aula e o checklist) está em [`../../missoes.md`](../../missoes.md#-missão-1-expressrouter-e-controllers).

## Como rodar

```bash
npm install
npm run dev
```

Num **segundo terminal** (no Windows, use `curl.exe`):

```bash
curl http://localhost:3000/produtos
```

Para ver o jeito **antigo** (tudo num arquivo só), desligue o servidor e rode `npm run antes`.

Para desligar o servidor: `Ctrl + C` no terminal dele.
